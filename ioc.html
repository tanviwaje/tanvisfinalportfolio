Instant Ownership Check

An AI-driven solution for automating property title verification and fraud risk analysis for secured lending.

Python TensorFlow Scikit-learn FastAPI SQL NLP OCR

01 — PROFESSIONAL CONTEXT

Data Analyst Internship

This project was developed during my Data Analyst internship at SLO Technologies (Advarisk), where I worked on the Instant Ownership Check (IOC) platform.

The platform focused on automating property title verification and fraud risk analysis for secured lending.

02 — PROBLEM

Property Title Verification

Property registration documents can contain highly fragmented and unstructured information, including documents written in regional languages.

The IOC platform was designed to process this information and support the verification of transaction histories, ownership chains, property values, and potential fraud risks.

03 — DOCUMENT INTELLIGENCE

NLP & OCR Pipeline

Robust NLP and OCR pipelines were developed to process unformatted property registration documents and extract important ownership and transaction information.

OCR

Used to ingest information from unformatted property registration documents.

NLP

Used to process and interpret fragmented document information.

BERT

Applied as part of the NLP pipeline for processing document information.

LayoutLM

Used within the document-processing approach for handling structured information from documents.

04 — EXTRACTION RESULT

90%+ Extraction Accuracy

The document-processing pipeline achieved a 90%+ accuracy rate in extracting critical transaction histories and ownership chains from fragmented property registration data.

05 — PROPERTY VALUATION

Spatial-Comparable Machine Learning

A spatial-comparable machine learning model was developed to cross-reference target asset values against recent localized registration data.

This approach supported more accurate property valuation and helped mitigate collateral-focused lending fraud.

06 — FRAUD RISK ANALYSIS

Anomaly Detection

Specialized anomaly detection models were trained to proactively identify high-risk indicators associated with property ownership and lending activity.

Multiple Loan Pledges

Flagging properties that may be concurrently pledged against multiple loans.

Multi-Owner Flipping

Identifying short-term multi-owner flipping patterns as potential high-risk indicators.
