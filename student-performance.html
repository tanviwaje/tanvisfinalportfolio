PREDICTIVE ANALYTICS PROJECT

Student Performance Prediction System

A machine learning application developed using Python and MySQL to predict student academic outcomes through data preprocessing, exploratory analysis, and classification models.

Python MySQL Pandas NumPy Matplotlib Scikit-learn

01 — OVERVIEW

Project Overview

The Student Performance Prediction System is a machine learning application designed to predict student academic outcomes using data-driven techniques.

The project combines Python-based data analysis and machine learning with MySQL for data management.

02 — DATA PREPARATION

Data Preprocessing & Exploration

The project involved preparing the data before applying machine learning models and performing exploratory data analysis to understand the available information.

Data Preprocessing

Prepared the data for machine learning analysis before model development.

Exploratory Analysis

Analysed the data to understand patterns and characteristics relevant to student outcomes.

Pandas & NumPy

Used Python libraries for data manipulation and numerical analysis.

Matplotlib

Used for visual exploration and understanding patterns within the data.

03 — DATABASE

MySQL Integration

MySQL was used as part of the application to manage the project's data and support the overall data workflow.

04 — MACHINE LEARNING

Classification Models

01 Logistic Regression
02 K-Nearest Neighbors (KNN)
03 Random Forest

05 — EVALUATION

Model Evaluation

The implemented classification models were evaluated using accuracy and classification metrics to assess their predictive performance.

Evaluation approach

Accuracy and classification metrics were used to compare and evaluate model performance.

06 — KEY TAKEAWAY

Predicting Academic Outcomes

This project demonstrates the application of Python, data analysis, database management, and machine learning classification techniques to a student performance prediction problem.
